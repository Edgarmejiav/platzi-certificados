¿Cuál es la diferencia entre las anotaciones @Id y @EmbeddedId?
La primera se usa para describir una clave primaria sencilla y la segunda se usa cuando la clave primaria es compuesta.
5.
¿Para qué se utiliza la propiedad spring.datasource.url?

Para definir el motor, ubicación, puerto y nombre de la base de datos.

¿Qué anotación se necesita para denotar que una clase es una entidad para JPA?
@Entity
7.
¿Qué se le debe pasar al operador diamante de la interface CrudRepository cuando se implementa?

La clase que representa la entidad y el tipo de su clave primaria.
8.
¿Qué diferencia existe entre las anotaciones @Service y @Component?
Su única diferencia es semántica. @Service no agrega nada más especializado a @Component.
9.
¿Para qué sirve la anotación @RequestMapping en el encabezado del controlador?
Para definir el Path sobre el cual van a responder todos los servicios del controlador.

¿Qué hace la anotación @InheritInverseConfiguration de MapStruct?
